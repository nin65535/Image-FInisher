# 設定・状態管理仕様

## 1. 設定の分類

設定はアプリ共通設定とPC・利用者固有設定に分ける。

### 1.1 アプリ共通設定

- ComfyUI拡大ワークフローの参照先と差替対象ノード
- AutoMosaicワークフローの参照先と差替対象ノード
- 回収対象出力
- 対応拡張子
- 画像処理の固定値

共通設定はリポジトリ内のJSONで管理し、起動時に検証して読み込む。

### 1.2 個人設定

- ComfyUI API URL
- 必要な外部ツールのパス
- 前回使用したモザイク強度
- 前回選択した入力フォルダ（採用する場合は実装時に画面仕様へ明記する）

個人設定は`%LOCALAPPDATA%\ImageFinisher\settings.json`へ保存する。書込みは一時ファイルを介した原子的置換とする。

## 2. モザイク強度

初回起動時はAutoMosaicワークフローの既定値を使用する。利用者が実行に使用した値を個人設定へ保存し、次回起動時に復元する。入力値はワークフローが受け付ける範囲で検証する。

## 3. ジョブ状態

最低限、次の状態を持つ。

- 待機中
- 実行中
- 完了
- 失敗
- キャンセル要求中
- キャンセル

ジョブ、画像、工程の状態をSQLiteへ保存する。ブラウザ再読込後も進捗と結果を復元できるようにする。

## 4. 保存する履歴

- ジョブIDと登録・開始・終了時刻
- 入力フォルダと自動決定した完成フォルダ
- 有効工程と実行時設定
- 元画像名、グループ名、完成画像名
- 画像ごとの工程状態、エラー、再実行回数
- 完成ファイルのパスと検証結果

CSVやJSONの対応表ファイルは出力しない。画面とSQLite内部履歴を正本とする。

## 5. 履歴クリア

履歴は自動削除せず、利用者が画面から明示的にクリアするまで保持する。完了、失敗、キャンセル済みだけを削除対象とし、待機中、実行中、キャンセル要求中は削除しない。

## 6. 再起動と再実行

アプリ異常終了時に実行中だったジョブと画像は、次回起動時に失敗として記録する。出力と一時ファイルを確認してから、失敗画像だけを再実行できるようにする。成功済み画像は再処理しない。
