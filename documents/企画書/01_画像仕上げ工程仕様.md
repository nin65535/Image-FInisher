# 画像仕上げ工程仕様

## 1. 標準工程

1. 入力フォルダを選択する
2. 対象PNG、命名規則、グループ件数、出力衝突を事前検証する
3. 実行予定の工程と命名結果を確認する
4. 画像ごとにリネーム、拡大、モザイクを実行する
5. 有効な全工程が成功した画像を`../finished`へ確定する
6. 成功・失敗・キャンセル件数を表示する
7. 完成フォルダをBandiViewで開き、目視検品する

## 2. 工程順

工程順は次で固定する。各工程は個別に有効・無効を切り替えられる。

```text
リネーム → 拡大 → モザイク
```

想定例：

- 成人向け投稿用：リネーム＋拡大＋モザイク
- 全年齢納品用：リネーム＋拡大
- 拡大済み画像：リネーム＋モザイク
- 既存画像の修正：モザイクのみ

## 3. リネーム工程

ファイル名末尾の`_<数字列>_`を除いた部分をグループ名とする。グループ内で元ファイル名を昇順に並べ、`0001`から4桁連番を付与する。

```text
scene01_00004_.png → scene01_0001.png
scene01_00019_.png → scene01_0002.png
```

数字列の桁数は固定しない。1グループが9999枚を超える場合、または規則に一致しないPNGが1枚でも存在する場合は、ファイルを変更する前にバッチ全体を停止する。

## 4. 拡大工程

- ComfyUIの`RealESRGAN_x4plus_anime_6B`で4倍拡大する
- 4倍画像をLanczos法で50%へ縮小する
- 完成寸法は元画像の幅と高さをそれぞれ2倍とする
- 元画像が非正方形でも縦横比を維持する
- クロップや余白追加による正方形化は行わない

## 5. モザイク工程

- ComfyUI AutoMosaicの実機検証済みワークフローを使用する
- 画面から変更できる値はモザイク強度だけとする
- その他の値はワークフロー側の固定値を使用する
- モザイク強度は前回値を復元する。初回はワークフロー既定値を使用する
- 自動処理後もBandiViewによる目視検品を必須とする

## 6. 成功と失敗

処理の確定単位は画像1枚とする。画像ごとに有効な全工程を専用一時領域で完了させ、出力を読み込めることと寸法を確認してから完成フォルダへ移動する。

一部画像が失敗しても成功済み画像は保持する。失敗画像には工程とエラーを記録し、失敗画像だけを再実行できるようにする。

## 7. キャンセル

キャンセル要求時は現在処理中の1枚について全工程と完成フォルダへの確定を終えてから停止する。次の画像は開始しない。未着手画像はキャンセル扱いとし、入力原本は変更しない。

## 8. 人間が行う工程

画像内容、破綻、モザイク範囲および投稿規約への適合は自動保証しない。完成後の閲覧・比較・品質判断はBandiViewで行う。
