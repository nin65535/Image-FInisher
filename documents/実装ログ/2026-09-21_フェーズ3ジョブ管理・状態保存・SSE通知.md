# フェーズ3 ジョブ管理・状態保存・SSE通知 実装記録

## 結果

2026-09-21 にフェーズ3を実装し、画像ファイルを変更しない状態管理テストジョブを永続化・実行・復元できるようにした。

- `%LOCALAPPDATA%\ImageFinisher\jobs.sqlite3` にジョブ、画像、工程、入出力対応、エラーを保存するSQLiteスキーマを追加した
- 同時実行数1のFIFOジョブキューと、画像単位で進捗を保存するテスト実行器を追加した
- ジョブ登録、一覧・詳細、キャンセル要求、完了履歴クリアのAPIを追加した
- ジョブ登録後の状態変化と完了をSSEで通知し、15秒間隔のコメントで接続を維持するようにした
- アプリ起動時に待機ジョブをキューへ戻し、実行中・キャンセル要求中だったジョブ、画像、工程を失敗として記録するようにした
- 完了、失敗、キャンセルだけを履歴クリア対象とし、活動中のジョブを保護するようにした
- 画面に永続履歴、処理数、結果件数、画像詳細、キャンセル要求、履歴クリアを追加した

フェーズ3のテストジョブは管理基盤の検証専用であり、入力原本と完成フォルダには書き込まない。実ファイル処理はフェーズ4以降でこの実行器へ接続する。

## API

| メソッド | パス | 用途 |
| --- | --- | --- |
| `POST` | `/api/jobs/test` | 事前検証済みフォルダから状態管理テストジョブを登録 |
| `GET` | `/api/jobs` | 保存済みジョブ一覧を取得 |
| `GET` | `/api/jobs/{job_id}` | 画像・工程を含むジョブ詳細を取得 |
| `GET` | `/api/jobs/{job_id}/events` | ジョブ状態をSSEで購読 |
| `POST` | `/api/jobs/{job_id}/cancel` | 協調キャンセルを要求 |
| `DELETE` | `/api/jobs` | 終了済み履歴だけを削除 |
